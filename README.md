# 모멘트 업무 대시보드

외부 패키지나 API 키 없이 실행하는 한국어 개인 업무 대시보드입니다. 예시 데이터가 포함되어 있습니다. 실제 사용자 평가를 받은 제품이라는 뜻은 아닙니다.

## 실행

```sh
cd /workspace/-
python3 -m http.server 8000 --bind 0.0.0.0
```

로컬 컴퓨터에서는 저장소 폴더에서 같은 서버 명령을 실행하고 브라우저로 http://localhost:8000 에 접속합니다. 클라우드에서는 제품이 제공하는 포트 접근 기능이 있는 경우 이용하세요.

## 사용법

1. **새 업무**: 업무 이름, 프로젝트, 마감일, 우선순위를 입력합니다.
2. 업무 왼쪽 원: **할 일 → 진행 중 → 완료 → 할 일** 순서로 상태를 변경합니다. 요약과 마감 일정이 자동 갱신됩니다.
3. 업무 이름: 수정 창을 엽니다. **삭제**는 확인 후 실행됩니다.
4. 검색창: 업무 이름 또는 프로젝트를 검색합니다. 탭으로 상태를 필터링합니다.
5. **집중 시작**: 25분 타이머를 실행합니다. 일시정지, 계속하기, 초기화를 지원합니다. 새로고침하면 타이머는 초기화됩니다.
6. **데이터 내보내기**: 업무 데이터를 JSON 파일로 보관합니다. 가져오기는 제공하지 않습니다.

업무는 브라우저 localStorage에 자동 저장됩니다. 같은 브라우저와 주소·포트를 사용하면 새로고침 후에도 유지됩니다. 다른 기기와 동기화되지 않으며 브라우저 데이터를 지우면 사라집니다. To Do의 팀 공유, 서버 DB, 알림 기능은 포함되지 않습니다. 날짜는 브라우저의 현지 시간 기준입니다.

## 구성

- index.html: 화면과 편집 대화상자
- assets/style.css: 데스크톱·모바일 반응형 디자인
- assets/app.js: 업무 CRUD, 검색, 필터, 저장, 내보내기, 타이머

별도 설치·빌드 과정이 없습니다.

## GitHub Pages 배포

배포 파일은 `gh-pages` 브랜치의 루트에 있습니다. GitHub 저장소의 Settings → Pages → Build and deployment에서 Source를 **Deploy from a branch**, Branch를 **gh-pages**, 폴더를 **/(root)**로 선택하고 Save를 누릅니다. 배포 완료 후 Pages 화면에 표시된 주소를 사용하세요.

GitHub Pages는 사이트 파일을 공개합니다. 업무 내용은 사용자 브라우저에만 저장되며 저장소에 업로드되지 않습니다. 방문자마다 독립된 업무 목록이 있습니다. 기본 Pages 주소와 사용자 지정 도메인은 별개의 저장 공간이므로 계속 같은 주소를 사용하세요.


## Google 캘린더 연결

사이트의 **Google 연결**을 누르고 GPT 일정 관리에 사용하는 Google 계정으로 로그인하여 캘린더 조회 권한을 허용합니다. 연결 후 드롭다운에서 일정이 저장된 캘린더를 선택하세요. 오늘부터 30일 동안의 일정(반복 일정 포함)을 불러옵니다. GPT에서 등록·수정·삭제한 일정은 **일정 동기화**를 누르면 반영됩니다. To Do와는 별개이며 캘린더를 변경하지 않습니다.

OAuth 클라이언트는 `assets/calendar.js`에 공개 식별자로 설정되어 있습니다. Google Cloud의 Google Calendar API 활성화, OAuth 대상의 테스트 사용자 등록, 웹 클라이언트의 승인된 JavaScript 원본 `https://nailit9471-sketch.github.io` 설정이 필요합니다. 개발용 원본은 별도로 등록해야 합니다. 리디렉션 URI와 클라이언트 보안 비밀번호는 사용하지 않습니다. 조회 범위는 `https://www.googleapis.com/auth/calendar.readonly`입니다.

Google 로그인 라이브러리와 Calendar API에 인터넷 연결이 필요합니다. 토큰과 일정은 메모리에만 유지되고 새로고침·로그인 만료 후 다시 연결합니다. **연결 해제**는 표시된 일정을 지우고 Google 토큰 취소를 요청합니다. 일정 시간은 브라우저 현지 시간 기준이며 종일 일정의 종료일은 Google의 배타적 종료일 규칙에 따라 표시합니다.

오류 안내:
- `origin_mismatch`: 승인된 JavaScript 원본이 사이트 원본과 일치하는지 확인합니다.
- `access_denied` 또는 테스트 사용자 제한: 로그인 이메일을 OAuth 테스트 사용자로 추가합니다.
- 403: Google Calendar API 활성화와 캘린더 조회 권한을 확인합니다.
- 로그인 창 차단: 이 사이트의 팝업을 허용하고 다시 연결합니다.

개인 계정의 실제 OAuth 로그인은 사용자 브라우저에서 확인해야 합니다. 자동 검증은 모의 Google 응답으로 목록 선택, 페이지 처리, 종일·시간 일정, 취소 일정 제외, 재동기화, 만료·권한 오류, 연결 해제, 모바일 레이아웃을 확인했습니다.
